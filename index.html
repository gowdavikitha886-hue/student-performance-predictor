🎓 SPPS is a web app — start the server first

This file is only a launcher. The real app (login, training, predictions) runs on a local Node.js server.

Step 1 — in a terminal, inside this folder, run:
npm start

Step 2 — open the app in your browser:

http://localhost:3000/
Demo admin: admin@spps.local / admin123
If the button does not open, the server is not running yet (or it is on another port — check the terminal output).
